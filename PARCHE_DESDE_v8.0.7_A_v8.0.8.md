# Parche v8.0.7 → v8.0.8

Parche focalizado para consolidar respuestas generales a consultas de candidatos provenientes de APP + EMAIL.

Incluye:
- guía general automática basada en consultas pendientes;
- conteo separado APP / EMAIL;
- desaparición de consultas ya respondidas o programadas del Chat operador;
- reaparición automática cuando existe una nueva consulta posterior;
- exclusión de rebotes y automáticos del Chat operador.

No modifica la base profesional de candidatos ni requiere migración adicional.
