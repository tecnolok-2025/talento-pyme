# Talento PyME v7.10.12 — LEER PRIMERO

Esta revisión parte de **v7.10.11**.

## Cambios principales
- Feedback táctil/visual global para botones y controles interactivos.
- Protección global contra clics repetidos accidentales sobre el mismo control.
- Botones críticos muestran estado ocupado y quedan deshabilitados mientras la acción está en curso.
- Corregido el borrado de búsquedas con postulaciones: ahora se cierran y preservan para mantener trazabilidad.
- Versión unificada en frontend, API, PWA y archivos de despliegue.
- README y `CURRENT_VERSION.txt` dejan explícita la versión operativa actual.

## Importante sobre GitHub
Los archivos `AUDITORIA_*`, `LEER_PRIMERO_*`, `RELEASE_*` de versiones anteriores son **históricos**. GitHub los seguirá mostrando mientras permanezcan en la raíz. El parche no puede borrar archivos remotos por sí solo. Para una raíz limpia, seguir `LIMPIEZA_GITHUB_v7.10.12.md`.

No agrega migraciones de base de datos.
