# Talento PyME v8.0.5 — Release final

## Objetivo
Distinguir automáticamente consultas ya resueltas por la base de conocimiento de consultas nuevas que necesitan ampliar respuesta.

## Implementación
- Clasificación dinámica por mensaje de usuario.
- Contadores separados en Chat operador.
- Etiqueta por consulta y estado de la última consulta de cada hilo.
- Desglose de consultas pendientes en Correo / Consultas.
- Umbral conservador para coincidencias con conocimiento reutilizable.
- Sin migración de base de datos.
