# Talento PyME v9.0.0

## Motor de búsqueda profesional por evidencia

- Base: v8.0.10. La v8.0.11 no se usa como base.
- Auditoría sobre 600 candidatos del respaldo lógico del 06/10/2026.
- Índice ampliado a fuentes profesionales reales, no sólo clasificación propuesta.
- Equivalencias controladas por familias profesionales.
- Búsqueda compuesta con todos los conceptos obligatorios.
- Abreviaturas cortas con coincidencia por token para reducir falsos positivos.
- Orden por relevancia profesional cuando hay texto libre.
- Resúmenes generados por IA excluidos como única fuente de coincidencia.
- Sin cambios en score, clasificación, seniority o expertise.
- Sin migración de Neon.

Pruebas focalizadas: 25/25 aprobadas. Sintaxis de API validada.
